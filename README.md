# Tech Practice Hub

Coding practice in the browser for foundation students at the University of Bedfordshire.

## What it is

A website where students practise the language of tech by writing real code: Python, HTML and CSS, and a first AI task. Nothing needs installing.

## Who it is for

Students on the foundation tech pathways, and their teachers (ppt slides and handouts - on my OneDrive).
